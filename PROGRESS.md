# TaskFlow Project — Progress Log

## What this project is
A full-stack team task/project management app (like mini-Trello), built to learn
backend (Spring Boot) + frontend (React) for placement prep. Complete beginner,
learning every concept alongside building.

## Tech stack
- Backend: Java 17, Spring Boot 4.1.0, Maven
- Database: MySQL (local, db name: taskflow_db)
- ORM: Spring Data JPA / Hibernate
- Security: Spring Security (added, not yet configured for real auth)
- Frontend: React (not started yet)
- IDE: VS Code (Java Extension Pack + Spring Boot Extension Pack)
- OS: Windows
